HPC MCP Server

A web-accessible MCP service that connects a language model with HPC tools. Users can ask questions in natural language, and the server can either answer directly or call a backend tool when the task requires it.

Available

Deployed on Tapis Pods

The current working service is deployed as a CPU Tapis Pod and can be reached anywhere with an internet connection.

MCP Endpoint

Agent Ready

Claude Code or another MCP client can connect through HTTP transport at the public MCP endpoint.

CPU Version

Small Local Model

The current deployment uses a compact CPU language model for intent routing and basic chat.

Current Capabilities

General Chat

The LLM can answer normal user questions directly when no external tool is needed.

Tool Routing

The LLM interprets the request and decides whether to call a backend MCP tool.

Training-Time Prediction

The estimator predicts one parameter update time for distributed LLM training on Vista and Perlmutter.

curl --http1.1 -X POST https://hpcmcpservercpu.pods.icicleai.tapis.io/chat \
  -H "Content-Type: application/json" \
  -d '{"prompt":"Predict the time cost of one parameter update for the llemma-7B distributed training configuration on Perlmutter. Answer with microseconds and seconds.","max_new_tokens":120}'
